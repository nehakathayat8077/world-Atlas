# 🌍 World Atlas

World Atlas is a responsive full-stack web application that allows users to explore countries and view information such as their capital, population, flag, and interesting facts.

## 🚀 Live Demo

🔗 **Frontend:** https://world-atlas-8077.netlify.app/

🔗 **Backend:** https://world-atlas-l6jm.onrender.com/

## ✨ Features

- 🌎 Explore countries
- 🏳️ View country flags
- 🏛️ View capital cities
- 👥 View population
- 💡 Interesting facts about countries
- 📱 Responsive design
- 🌙 Dark-themed UI
- 📩 Contact form
- 💾 Contact messages stored in MongoDB
- 🔄 React Router navigation
- 🚀 Deployed frontend and backend

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS
- dotenv

### Deployment
- Netlify — Frontend
- Render — Backend
- MongoDB — Database
